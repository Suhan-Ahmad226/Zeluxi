# Zelux

Modern Bangladesh-focused single-store ecommerce platform.

## Architecture
- Next.js 16 App Router + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- PostgreSQL + Prisma
- Supabase Auth
- Cloudinary media
- Redis where caching/background work needs it
- Vercel deployment

## Principles
Server-first, secure, fast, accessible, responsive, transaction-safe, and maintainable. Client input is never the final financial truth.

## Development
Copy `.env.example` to `.env.local`, configure services, then install dependencies and run the development server.
